EveJS v0.12.6 Universal Linux Setup v1.8.1
Updater Hotfix Verification
================================================

Observed live failure
---------------------
v1.8 correctly discovered Cargo through the Installer, but the Python updater
dereferenced the rustup-managed ~/.cargo/bin/cargo proxy with Path.resolve().
The executable therefore became ~/.cargo/bin/rustup and the Market build was
incorrectly invoked as:

  rustup build --release

v1.8.1 preserves the Cargo proxy pathname and verifies `cargo --version` before
staging.

Mod finding
-----------
The installed mod did not cause the failure. Mods are protected update state.
v1.8.1 now hashes/manifests the complete existing mods tree and requires the
staged tree to be identical before commit.
