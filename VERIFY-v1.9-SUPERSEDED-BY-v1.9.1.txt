EveJS v0.12.6 Universal Linux Setup v1.9
Living Universe Compatibility Verification
============================================================

Scope
-----
One Installer/Launcher architecture supports three mutually-exclusive runtime states:
1. Stock EveJS v0.12.6.
2. Loader Living Universe at mods/x-eve-living-universe/loader.js.
3. X-Patch Living Universe 0.3.2 with verified _local/x-eve-patch/install.json.

Loader-LU + X-Patch-LU together are deliberately rejected.

Protected-source rule
---------------------
The v1.9 compatibility layer does not invoke X-Patch install/repair/uninstall and
does not write build output into the installed EveJS/LU/X-Patch Rust source.
Market compatibility builds use an external copied source tree and external
CARGO_TARGET_DIR under the sibling .evejs-linux-runtime hierarchy.

Normal game runtime persistence is not classified as source rewriting. X-Patch's
own supplied topology synchronization remains part of its startup contract and
acts on the runtime Market database, not on its tracked source payload.

Known live-test boundary
------------------------
This execution environment has no native Cargo/rustc toolchain, so v1.9 does not
claim a real Rust compilation of stock and X-Patch Market here. The exact build
orchestration is tested with an external-copy fixture, but final host-native
compile/start acceptance remains a live Linux test.

The X-Patch-specific startup gate must be accepted live only after its external
Market binary is compiled on the user's host and both no-op RPC probes pass
before the EveJS Node server starts.
