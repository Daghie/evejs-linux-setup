Live v1.9 failure reproduced from user log
-------------------------------------------
The clean setup reached successful Market build/doctor and copied-client setup,
then failed entering portable-launcher installation with:

  line 1745: repo: unbound variable

Root cause:

  local repo="$1" tools="$repo/.evejs-linux-tools"

under Bash set -u expands $repo before that same local statement establishes it.

v1.9.1 correction:

  local repo="$1"
  local tools="$repo/.evejs-linux-tools"

The corrected function was also executed under set -u against a disposable
runtime-tools destination: PASS.
