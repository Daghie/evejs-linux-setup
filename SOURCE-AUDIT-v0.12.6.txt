Port / listener topology
------------------------
v0.12.6 retains the Linux runtime topology used by the launcher:
- 443   native loopback HTTPS/CDN responder
- 5222  XMPP
- 26000 Game
- 26001 Image
- 26002 Gateway HTTP
- 26003 Gateway local TLS
- 26400 Redshift
- 40110 Market HTTP
- 40111 Market RPC

v0.12.6 Docker configuration now also explicitly publishes 40111 on loopback.
That aligns with, rather than changes, the native Linux launcher's existing
40110/40111 ownership contract.

Market daemon change
--------------------
v0.12.6 market-server local config removes configurable host strings.
The Rust daemon now enforces loopback internally for its native listeners.
Ports remain 40110 and 40111.

This is compatible with the Linux launcher, which already connects only to:
  http://127.0.0.1:40110
  127.0.0.1:40111
