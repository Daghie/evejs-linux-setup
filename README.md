# EveJS Universal Linux Setup

Installer and launcher for running [EveJS](README-LINUX.md) on Linux (standard distributions and SteamOS) with
the official EVE client under Steam Proton.

- `main` holds the Stock line. Each released version is a tag (`v1.4` … `v1.18`, then `v1.18.1` …).
- `living-universe` holds the Living Universe editions (`v1.12-lu`, and the hand-made `v1.14-lu-dev` launcher files).
- Each version's GitHub Release carries the archive exactly as shipped, including large binaries that are
  kept out of git (the SteamOS portable payload and the integrated Living Universe files).

Usage for the current version: see [README-LINUX.md](README-LINUX.md).
